# Vertical-crop defect patterns: cause, fix, proof

For 16:9-to-9:16 auto-reframe grading. Consult before diagnosing;
do not re-litigate a row already closed.

| Pattern | Root cause | Fix (where) | How proved |
|---|---|---|---|
| Head/face cut at frame edge | Window narrower than close-up head; join/keyword zoom punches cropped ~6% of edges | Video zooms capped (join <=1.05, keyword/slow <=1.03, render_template); corner-snap (`_snap_corner`) when the window lands near the left edge; never widen the window past H*9/16 (aspect law — widening stretches the picture); reposition x, lock an edge, pick another second, or replace | Same-timestamp before/after hook vision per clip |
| Partial body only (hands/legs/torso, no face) at clip open | Leading no-face chunks must not guess: forward-fill smeared a later face over an entrance | Leading-None stays None (center = neutral); `test_leading_none.py` pins it | Vision A/B reverted the fill the same night it shipped |
| Half-cut burned-in text (counters, gauges, dials) | Tracker pans the narrow window off static graphics | Per-moment anchor lock (`"anchor"` on the moment: left/center/lock-*; lock also disables face override) after checking audit strips for which side holds graphic + face. Lock ONLY when graphic and face share a side (both left: lock-left keeps both); face/graphic on opposite sides is unfixable by anchor — replace the moment, never lock (lock-left on a right-side face cuts the subject to save the graphic) | Re-render + hook vision per locked moment; lock-left proved: DAY60 whole in 5/7 sampled seconds |
| Caption-side overflow (long tokens off viewport) | 96px display type wider than the 960px layer | Wrap guards on `.capline` + `#hook` (`max-width:100%;overflow-wrap:anywhere`); sizes/fonts untouched | Source-contains test + next renders' QC |
| Money value split in two styles | `,000`-led fragments built as separate spans with independent scale | Merge punctuation-led fragments into previous span at build time | Unit + edge cases + vision: uniform `$250,000` |
| Empty no-subject cold opens | Detector phantom on title cards (no person, confident box) hijacked selection and crop | `MIN_SCORE=0.5` gate on all four detector loops; retune the constant if true faces ever score lower, never remove it | Live probe: phantom 0, heroes kept; cold open landed on participant |
| Dead captions + static hook | One syntax error kills the whole timeline (parse fail, no `tl`) | Extract inline script, `node --check` before every render batch | Hook-alive + captions-back vision proof |
| Hollow captions (stroke swallows fill) | Headless Chromium falls back without embedded fonts; stroke paints over fill | Base64 font embed + explicit `-webkit-text-fill-color` + `paint-order` in every keyword class | Zoomed caption-band vision |
| Audit scores collapse, pixels unchanged | Harsh re-grade drift, not a regression | Measure first (brightness/contrast/old-vs-new side-by-side); another rebuild on drift destroys working output | m15 hook: identical pixels, opposite verdicts |
| Grading standard | Owner's bar only: face cut at edge, partial body with no face, half-cut text, empty frame, blur. Whole-face tight close-ups, readable backs/action, and redundant-graphic blemishes are style, not defects | Calibrate the grader prompt to the bar before counting; re-verify machine-derived verdicts with vision when the service flaked | 18/44 owner-bar postable vs 6/44 strict on the same renders |
| Hook title or caption pill covers a face | Fixed title/caption bands overlap the face zone (high full-body faces, huge close-ups) | Per-moment `text_y` {hook_top, cap_top}: title below high faces or to the top sliver for huge ones, captions above low faces; probe face boxes at hook + body thirds; text-grade gate 0.3 with crowd veto kept, crop gate 0.5 never lowered for this | Re-render + hook vision per moment (title clear of eyes, faces whole) |
| Single-still fail, whole clip at stake | One bad hook/mid still may be a 2-second region, not a bad clip | 7-frame persistence scan (every ~5s across the clip): defect in >=3/7 frames = persistent, fix or replace the moment; defect in 1-2/7 = single region, moment surgery (trim/shift start past it, or strip its cold open) | m31 AY79 in 1/7 (title card at moment start) -> start +3.2s; m7 150-cut in 3/6 (through body) -> lock-left |
| Hook defect survives a main-timeline fix | The hook shows the cold-open segment, not main start — surgery on the main range changes nothing | Read the hook timestamp first (hook time < co_dur = co content): move or repair the co itself (manual `"co"` override to engaging seconds), not the moment start; when the hook fails but the mid passes, point co at the mid's verified second (co = start + dur/2 − 1); for wide groups the crowd veto falls back to a centered crop that slices edge people, so use a solo second (PTC/reaction close-up) as co; re-grade the hook to prove it | Hook pixel-identical after a main-start shift; passed only after the co itself moved |
